CS 300 portfolio with Project One analysis, Project Two course sorting program, and reflection

CS 300 Reflection

What was the problem you were solving in the projects for this course?
In the first project, I examined the runtime and memory usage of various data structures. In the second project, I developed a program designed to sort and display Computer Science courses in alphanumeric order.

How did you approach the problem? Consider why data structures are important to understand.
I divided each project into manageable steps and adhered to the specified requirements. I assessed the ways different data structures organize and access information, as selecting the appropriate structure can significantly impact a program’s efficiency in terms of speed and memory usage.

How did you overcome any roadblocks you encountered while going through the activities or project?
When I faced difficulties, I revisited the instructions, verified my work, and tackled the problem incrementally. This approach enhanced my comprehension of how the program’s logic and data structures interacted.

How has your work on this project expanded your approach to designing software and developing programs?
These projects underscored the importance of planning before commencing coding. Considering the storage, retrieval, and presentation of information enabled me to make more informed design decisions.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
I learned to structure code in a clear manner and select meaningful identifiers, which facilitates understanding and updating the code. Additionally, I recognize that selecting the right data structure can simplify the maintenance of a program as its requirements evolve.
